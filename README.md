# 🤖 Smart Daily Decision App

A cross-platform mobile application built with Flutter to help users make better daily decisions using smart algorithms.

## 🚀 About The Project

This app was developed as my CSCI410 project. It leverages Flutter's cross-platform capabilities to provide a seamless experience on iOS, Android, Web, and Desktop.

The goal is to simplify everyday choices, from simple "what to eat" dilemmas to more complex planning, using a structured decision-making process.

## 🛠️ Built With

*   [Flutter](https://flutter.dev/) - Google's UI toolkit for building natively compiled applications.
*   **Dart** - The programming language behind Flutter.
*   Supports: Android, iOS, Web, Windows, Linux, macOS

## ✨ Key Features

*   **Multi-Platform:** Run the same code on your phone, tablet, or computer.
*   **Structured Decisions:** (You can add what your specific algorithm or logic does here)
*   **User-Friendly Interface:** Built with Flutter's rich widget library.

## 📦 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   **Flutter SDK:** [Install Flutter](https://docs.flutter.dev/get-started/install) on your machine.
*   **IDE:** Android Studio, VS Code, or IntelliJ IDEA with Flutter/Dart plugins.

### Installation & Running

1.  **Clone the repository**
    ```bash
    git clone https://github.com/kassemaraji2020-create/smart-daily-decision-app.git
    ```
2.  **Navigate to the project folder**
    ```bash
    cd smart-daily-decision-app
    ```
3.  **Get the required packages**
    ```bash
    flutter pub get
    ```
4.  **Run the app**
    
    *   **On a connected device/emulator:**
        ```bash
        flutter run
        ```
    *   **For a specific platform (e.g., web):**
        ```bash
        flutter run -d chrome
        ```
